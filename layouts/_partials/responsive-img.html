{{- /* An that offers the browser several sizes of one photo. Hugo makes the smaller copies at build time (they never go in Git); the browser then downloads just the one that fits its screen. Copies are only made smaller than the original, never enlarged, and the original is offered as the largest choice (unless noOriginal is set). A PNG is served as WebP (quality 82) instead: Hugo would otherwise keep the PNG format, and a PNG photo runs to megabytes. Transparency is kept, and the logos and photos checked (2026-09-20) looked the same. That includes the largest choice, so the visitor never downloads the PNG itself. A JPEG stays a JPEG. If a crisp logo ever looks fuzzy this way, that is the place to make an exception. Params (dict): img (required) image resource, e.g. from .Resources.Get alt alt text ("" for a purely decorative image) sizes how wide the image is shown, for the browser's choice widths slice of widths to make, default 480 / 800 / 1200 noOriginal true = don't offer the full-size original (for thumbnails, so a phone never picks it) lazy true = load only when scrolled near class, title optional attributes */ -}} {{- $img := .img -}} {{- $widths := .widths | default (slice 480 800 1200) -}} {{- $src := $img -}} {{- /* `full` is the largest choice: the original, or for a PNG a WebP of the same size. */ -}} {{- $full := $img -}} {{- $format := " q82" -}} {{- if eq $img.MediaType.SubType "png" }}{{ $format = " webp q82" }}{{ $full = $img.Resize (printf "%dx%s" $img.Width $format) }}{{ $src = $full }}{{ end -}} {{- $srcset := slice -}} {{- range $widths -}} {{- if lt . $img.Width -}} {{- $r := $img.Resize (printf "%dx%s" . $format) -}} {{- $srcset = $srcset | append (printf "%s %dw" $r.RelPermalink $r.Width) -}} {{- if le . 800 }}{{ $src = $r }}{{ end -}} {{- end -}} {{- end -}} {{- if or (not .noOriginal) (eq (len $srcset) 0) -}} {{- $srcset = $srcset | append (printf "%s %dw" $full.RelPermalink $img.Width) -}} {{- end -}} , whichever smaller copy the browser actually downloads. */ -}} {{- printf " width=%d height=%d" $img.Width $img.Height | safeHTMLAttr }} alt="{{ .alt }}" {{- if .lazy }} loading="lazy" decoding="async"{{ end }} {{- with .class }} class="{{ . }}"{{ end }} {{- with .title }} title="{{ . }}"{{ end }}>
